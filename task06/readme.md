Було допрацьовано makefile та створено приклад юніт файлу. Для makefile було дещо перероблено попередні цілі, та додано install. Юніт файл має стандартні опції, опції для перезапуску та WorkingDirectory для корректної роботи з файлами логу.

Також було протестовано отриману службу. На перших ітераціях була проблема з роботою з логом, так як WorkingDirectory (атрибут юніт файлу) був доданий пізніше, екземпляр програми намагався створювати файли у корневій директорії, через що фактичний файл не створювався, та робота програми аварійно завершувалась. Надалі тестування показало успішне виконання, зупинку, перезапуск, тощо.
